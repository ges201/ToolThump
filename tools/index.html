All Tools

ToolThump is a collection of free online utilities organized into four categories: security, text, image and data. Every tool runs entirely in your browser - the files you open, the passwords you generate and the text you paste are never uploaded to a server.

There is no account to create and nothing to install: open a tool, use it, close the tab. Browse the full list below or jump straight to a category.

  • Password Generator Generate strong, random passwords.
  • Password Strength Checker Check the strength of your passwords.
  • Encoder / Decoder Encode and decode data in various formats like Base64, URL, and more.
  • Text Comparison Compare two pieces of text and highlight differences.
  • Text Case Converter Convert text to uppercase, lowercase, or title case.
  • Duplicate Words Finder Find and highlight duplicate words in a text.
  • Image Converter Convert images between different formats (PNG, JPG, WEBP, etc.).
  • Image Resizer Resize images to custom dimensions or standard aspect ratios.
  • Image Color Picker Pick a color from an image to get its HEX, RGB, and HSL values.
  • Background Remover Remove the background from images.
  • QR Code Generator Generate QR codes for URLs, text, and more.
  • Image Metadata Viewer View metadata of an image file.
  • File Comparison Compare two files and highlight differences.
  • Markdown Editor Create and preview Markdown documents with a simple and intuitive editor.
  • Video Subtitles Generator Generate SRT subtitle files from any video format with automatic speech recognition.
